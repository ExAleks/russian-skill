# Политика безопасности

## Поддерживаемые версии

Поддерживается только ветка `main`. Теги не поддерживаются отдельно: исправления
выходят в `main`.

## Что делает проект

`russian-skill` — это набор текстовых правил и два установочных скрипта
(`install.ps1`, `install.sh`). Скрипты:

- копируют файлы правил в каталоги конфигурации инструментов
  (`~/.claude/skills`, `~/.config/opencode/skills`, `~/.codex`, `~/.gemini`);
- дописывают блок правила в существующие `AGENTS.md` / `GEMINI.md`;
- не ходят в сеть, не запускают сторонний код, не собирают телеметрию.

## Что считается уязвимостью

В области действия:

- запись за пределы каталогов конфигурации (path traversal через `-ProjectDir`,
  `--project-dir`, `-HomeDir`, `XDG_CONFIG_HOME`);
- подстановка команд или аргументов через пути и переменные окружения;
- повреждение или потеря пользовательских файлов при установке (включая
  неидемпотентное поведение, дублирование блоков, порчу кодировки);
- обход проверок, из-за которых установщик сообщает об успехе, ничего не установив.

Вне области действия:

- поведение самих Claude Code, OpenCode, Codex CLI, Gemini CLI, Cursor, Cline, Windsurf;
- последствия применения правила «отвечать по-русски»;
- социальная инженерия и атаки, требующие уже скомпрометированной машины.

## Как сообщить

Не открывайте публичный issue. Используйте приватный канал GitHub:

1. Вкладка **Security** → **Report a vulnerability** (GitHub Security Advisories).
2. Опишите: версию/коммит, ОС и оболочку, шаги воспроизведения, ожидаемое и
   фактическое поведение, влияние.

Мы подтверждаем получение в течение 7 дней и стараемся выпустить исправление
в течение 30 дней. Публичного bug bounty нет; при желании указываем автора
отчёта в описании исправления.

## Проверка целостности

Установщики ничего не скачивают, поэтому проверять нужно только сам репозиторий:

```sh
git log --show-signature -1     # подпись коммита
git verify-tag <tag>            # подпись тега
```

Тесты воспроизводятся локально без сети:

```powershell
powershell -NoProfile -File .\tests\run-tests.ps1
```

```sh
./tests/run-tests.sh
```
