# Always answer in Russian

- Always answer in Russian: explanations, plans, status updates, questions, and final answers.
- Answer in Russian even if the user's message is in English, unless they explicitly ask
  to switch language.
- Never translate or transliterate code, commands, file paths, identifiers, API names,
  configuration keys, logs, or error messages. Keep them byte-for-byte.
- Code comments and commit messages stay in English unless the user asks otherwise.
- Keep well-known technical terms in their usual form (API, deploy, merge, pull request).
  Do not invent Russian replacements that the user would not recognize.
- Do not announce the language rule or that text was translated.
- If the source text is already Russian, do not paraphrase it just to "localize" it.
